# YzsKeepAlive 浏览器测试指南

## 测试准备

1. **启动开发服务器**:
```bash
cd test-app
npm run dev
```

2. **访问应用**:
打开浏览器访问: http://localhost:5174 (端口可能不同，查看终端输出)

## 功能测试清单

### 1. 基础功能测试
- [ ] **页面加载**: 确认页面标题显示"YzsKeepAlive Test Application"
- [ ] **组件切换按钮**: 确认有三个按钮: "Switch to Component A/B/C"
- [ ] **缓存信息**: 确认显示缓存大小和缓存键

### 2. 状态保持测试
- [ ] **Component A**:
  - 点击"Increment"按钮增加计数器
  - 在输入框中输入文字
  - 勾选复选框
  - 切换到Component B
  - 切换回Component A
  - **验证**: 计数器、输入框内容、复选框状态是否保持

- [ ] **Component B**:
  - 让计时器运行几秒
  - 选择下拉选项
  - 添加几个列表项
  - 切换到Component C
  - 切换回Component B
  - **验证**: 计时器继续运行、下拉选项保持、列表项保持

### 3. 缓存配置测试
- [ ] **Include配置**:
  - Component A和B在include列表中
  - 切换A↔B多次，观察缓存大小变化
  - **验证**: A和B应该被缓存

- [ ] **Exclude配置**:
  - Component C在exclude列表中
  - 切换到Component C，修改内容
  - 切换到其他组件，再切回Component C
  - **验证**: Component C的状态不应该保持

- [ ] **Max限制测试**:
  - max设置为2
  - 按顺序切换: A → B → C → A
  - **验证**: 缓存中只保留2个组件实例

### 4. 生命周期钩子测试
- [ ] **激活/失活钩子**:
  - 切换组件时观察"Event Logs"区域
  - **验证**: 每次切换都触发activated/deactivated事件
  - **验证**: 生命周期日志正确显示

### 5. 缓存管理测试
- [ ] **清空缓存**:
  - 点击"Clear Cache"按钮
  - **验证**: 缓存大小变为0，缓存键清空

- [ ] **缓存淘汰**:
  - 多次切换组件，观察缓存键列表
  - **验证**: LRU淘汰策略正常工作（最近最少使用的被淘汰）

## 预期行为

1. **状态保持**: 被缓存的组件状态应该完全保持
2. **生命周期**: onActivated/onDeactivated钩子应该正确触发
3. **缓存限制**: max配置应该限制缓存数量，使用LRU淘汰
4. **包含/排除**: include/exclude配置应该正确过滤组件
5. **性能**: 多次切换不应该有内存泄漏

## 问题排查

如果测试失败:

1. **页面无法加载**:
   - 检查控制台错误
   - 确认端口正确
   - 运行 `npm run build` 检查构建错误

2. **状态不保持**:
   - 检查组件是否在include列表中
   - 检查缓存大小是否增加
   - 查看生命周期日志

3. **钩子不触发**:
   - 检查组件是否使用了useKeepAlive钩子
   - 查看控制台是否有错误
